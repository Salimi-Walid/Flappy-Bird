# 🐦 Flappy Bird Clone (Python + Pygame)

A fully playable **Flappy Bird** clone made with Python and Pygame. Fly the bird through pipes, try to beat your high score, and enjoy the nostalgia!

![Gameplay](https://github.com/yourusername/flappy-bird-clone/assets/demo.gif)

h
## 🎮 Features

- 🎨 Retro-style graphics (original sprites)
- 🔊 Sound effects & background music
- 🏆 Score & high score system
- 🌄 Smooth background and ground scrolling
- 🔁 Endless pipes with collision detection
- 🎉 Easy to play, hard to master

---

## 📦 Requirements

- Python 3.13.3
- Pygame 2.6.1
